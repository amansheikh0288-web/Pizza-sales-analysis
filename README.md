# 🍕 Pizza Sales Analysis

An end-to-end Data Analytics project focused on analyzing pizza sales data to understand revenue performance, order trends, product performance, and customer ordering patterns.

## 📌 Project Overview

This project analyzes pizza sales data using MySQL, Microsoft Excel, and Power BI to transform sales data into meaningful business insights.

The analysis focuses on key sales KPIs, product performance, pizza category and size analysis, daily revenue trends, and peak ordering periods.

## 🎯 Business Objective

The objective of this project is to analyze pizza sales performance and identify patterns related to:

- Overall revenue and sales performance
- Total orders and pizzas sold
- Average order value
- Pizza category performance
- Pizza size performance
- Top-selling pizza products
- Daily sales and revenue trends
- Peak ordering hours

## 🛠️ Tools & Technologies

- MySQL / SQL - Data querying and analysis
- Microsoft Excel - Data preparation and exploration
- Power BI - Dashboard development and data visualization
